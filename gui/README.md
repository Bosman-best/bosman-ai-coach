# GUI module (Phase 2)

PySide6 application that wraps `core.reasoning_engine.get_advice()`.
Nothing tactical belongs here - this layer only renders MatchState in,
AdviceResponse out.

Suggested first file: `main_window.py` with a simple form matching
`MatchState` fields and an "Ask coach" button.

## Header banner

`assets/header_banner.png` is original artwork (a generic touchline
silhouette + tactics-board motif, no real person's likeness or club
branding) generated by `assets/generate_banner.py`. Regenerate/tweak it
with:

```bash
python gui/assets/generate_banner.py
```

If the PNG is ever missing, `main_window.py` falls back to a plain text
title bar rather than failing to launch.
